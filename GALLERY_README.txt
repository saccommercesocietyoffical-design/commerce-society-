UNLIMITED GALLERY SETUP
1. In your EXISTING Supabase project, open SQL Editor and run GALLERY_SETUP.sql once.
2. Upload ALL files from this ZIP to the ROOT of your existing GitHub Pages repository, preserving folder structure. Do not upload the ZIP itself.
3. Wait for GitHub Pages deployment, hard refresh site and admin.
4. Log in to /admin/, scroll to Gallery Management. Choose titles, category, and multiple photos; click Upload Photos.
5. Visit /en/index.html and /si/index.html to verify the gallery.
Notes: no application-imposed photo count limit, but Supabase storage/database quotas apply. Each photo must be JPG/PNG/WebP <=5 MB. Only upload school-approved photos with permission.
